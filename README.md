# Python Physics Toolbox

## 📌 Purpose
This repository is intended to store small Python tools and notebooks used for learning and applying physics concepts using scientific computing.

## ▶️ How to Run
- Install Python (>= 3.8)
- Open the notebook using Jupyter Notebook or JupyterLab
- Run cells sequentially

## 📚 Topics Covered
- Basic Python for physics
- Numerical calculations
- Data visualization
- Simple physics simulations
